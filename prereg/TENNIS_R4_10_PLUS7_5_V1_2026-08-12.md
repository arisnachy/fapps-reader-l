# KIRA Ω — TENNIS R4-10 +7.5 V1 — PREREGISTRATION

Frozen: 2026-08-12 America/Santo_Domingo
Status: PREREGISTERED / TARGET BLOCKS UNSCORED

## Purpose
Create an exact-date ATP weekday coverage family that is rank-disjoint from the existing T3 Top-3 selector.

## Frozen source
Tennis-Data annual ATP workbook pattern documented by the `welo::tennis_data()` implementation: `https://www.tennis-data.co.uk/{YEAR}/{YEAR}.xlsx` (fallback to the documented http scheme only if HTTPS transport itself is unavailable, with identical file fingerprint requirement within a run). Required worksheet is `{YEAR}`.

Required fields: `Date, Best of, Winner, Loser, WRank, LRank, W1,L1,W2,L2,W3,L3, Wsets,Lsets, Comment`. Source/file/schema failure is fail-closed.

## Frozen pregame selector
- ATP completed matches only: `Comment == Completed`;
- Best of == 3;
- ranks must be numeric and positive;
- exactly one participant has ATP rank 4..10 inclusive;
- opponent rank >=30;
- selected participant is the rank-4..10 player;
- no result/score/odds field creates, removes or ranks a candidate.

All qualifying exact-date matches enter the date pool. Retain max THREE distinct matches/date ranked prospectively by:
1. better selected rank (smaller integer);
2. larger opponent rank;
3. lexical selected player/opponent/tournament/round if fields exist;
4. stable source row index.

The rank band 4..10 is frozen specifically to be disjoint from T3 Top-3, not from target outcomes.

## Exact contract and settlement
Target contract: selected player **Game Line +7.5 games**, full match.

For completed BO3 matches, sum W1..W3 and L1..L3 ignoring blank/NA set cells. Map those totals to selected/opponent by Winner/Loser identity.
- WIN if `selected_games + 7.5 > opponent_games`;
- LOSS otherwise;
- no push at half-game line.

No +8.5/+9.5, match winner, set winner, one-set wrapper or other substitute.

## User Gate90
Each block independently requires:
- >=100 selected legs;
- >=70 candidate dates;
- observed leg survival >90%;
- observed whole daily-bundle survival >90%;
- exact Date present, completed-only, unique source-match identity, max3/date and complete settlement PASS.

Wilson95 intervals are reported diagnostically but are not vetoes under User Gate90.

Any DEV/OOS failure closes V1 without rank/line/date/source rescue.
